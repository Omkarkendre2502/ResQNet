## Fallback Behavior
If an image fails to load or is missing, the application renders a neutral grey placeholder block (`.resq-img-placeholder`) with exact CSS aspect-ratio reservation (16:9 for hero, 4:3 for services and about), ensuring zero cumulative layout shift (CLS) and avoiding any broken image icons.
